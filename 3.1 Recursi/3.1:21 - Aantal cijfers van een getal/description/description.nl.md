### Opgave

Schrijf een functie `aantal_cijfers_recursief(getal)` die op een recursieve manier het aantal cijfers berekent van `getal`. 

Test je code in Dodona. Let daarbij op dat je geen hoofdprogramma ingeeft.

### Voorbeeld


**Invoer:**

    > aantal_cijfers_recursief(678532)

**Uitvoer:**

    6
