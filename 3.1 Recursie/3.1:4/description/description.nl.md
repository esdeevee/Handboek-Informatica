### Opgave

Je kunt op verschillende manieren de macht berekenen van twee getallen.

* Schrijf een functie `macht_direct(a, b)` die simpelweg $$a^b$$ berekent en teruggeeft.  
* Schrijf een functie `macht_iteratief(a, b)` die $$a^b$$ berekent en teruggeeft op een iteratieve manier. 
* Schrijf een functie `macht_recursief(a, b)` die $$a^b$$ berekent en teruggeeft op een recursieve manier. 

Test je code in Dodona. Let daarbij op dat je geen hoofdprogramma ingeeft.

### Voorbeeld

**Invoer:**

    > product_direct(12, 5)

**Uitvoer:**

    60


**Invoer:**

    > product_iteratief(6, 7)

**Uitvoer:**

    42


**Invoer:**

    > product_recursief(13, 38)

**Uitvoer:**

    494
